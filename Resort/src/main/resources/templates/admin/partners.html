Partner Integrations

Partner Integration API

Use the partner REST API to connect delivery partner systems. Example endpoints:

  • GET /api/partners?apiKey=YOUR_API_KEY — list partner information for a valid partner key
  • GET /api/partners/me — return your partner details using X-API-KEY
  • POST /api/partners/pair — register a new partner link

Provide the generated API Key to partner apps so they can connect securely.
